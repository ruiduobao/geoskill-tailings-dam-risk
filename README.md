# geoskill-tailings-dam-risk

> Screen tailings dam bodies, reservoir areas, catchments, and downstream exposure using remote sensing change detection. Produce patrol priorities based on hazard, exposure, and evidence.

See [SKILL.md](SKILL.md) for full usage, inputs and outputs.

## Quick start

```bash
python tailings_dam_risk.py --bbox 116.30,39.85,116.45,39.95 --date-range 2023-06-01,2023-09-30 --facilities facilities.json --output-dir ./tdr
```
